How to run the simulator

  1. Open it. Save Annex6_Row_Operation_Simulator.html and double-click it. It opens in Chrome, Edge, Firefox or Safari. No installation and no internet are needed. On a phone or tablet, open the file from your Files app.
  2. You do the computing. The simulator only shows the rows in color, checks your work and explains mistakes. Nothing is solved for you unless you press “Use the correct matrix”.

Try it: the Annex 6 worked example

Solve x + 3y = 7 and 2x + 5y = 12. Follow the numbers below, then repeat each step with a deliberate mistake to see the explanation.

  1. Start. Open the Solve a system tab, keep “Sample problem”, press Start this problem. (The button below does this for you.)
  2. Step 0, Setup. Type the augmented matrix: R1 = 1, 3, 7 and R2 = 2, 5, 12, then Check setup. Try a mistake: write −5 instead of 5 and read the Setup (fact) explanation.
  3. Step 1. Operation: Add a multiple of a row, target row R2, row used R1, multiplier -2. You will see R2 → R2 − 2R1. Type the After matrix: R2 = 0, -1, -2 (R1 is already filled in). Press Check my step. Try a mistake: write 2 for the last entry. The checker shows why, solves 12 − 2(7) = −2, and names the failed prompt (Arithmetic and sign).
  4. Step 2. Operation: Multiply, target R2, multiplier -1. R2 = 0, 1, 2.
  5. Step 3. Operation: Add, target R1, row used R2, multiplier -3. R1 = 1, 0, 1.
  6. Conclusion. Type x = 1 and y = 2 in the Conclusion boxes and press Check conclusion. It checks your answer in the original equations.
  7. Review. Open the Error log tab to see every mistake the checker caught, and download it as CSV.

Good to know

  • Write numbers as 3, -2 or fractions like 1/2. The multiplier’s sign matters: -2 means R2 − 2R1.
  • Which move next? gives the Pivot Path hint. The teacher can switch it off with the checkbox at the top.
  • When a step is wrong you can try again, or use the correct matrix so one early slip does not spoil the rest.
  • Spot the error shows a student’s wrong step. Click the wrong entry, give the right value and the error type, then read the explanation.
  • You can type your own system (2 to 4 equations) in the Problem box, one equation per line.
